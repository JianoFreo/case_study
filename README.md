# Google Business Intelligence Professional Certificate - Module 3

This repository contains a complete, beginner-friendly data visualization and dashboarding project.

## What is included
- Synthetic Philippine-style datasets
- Data cleaning notebook
- Exploratory analysis notebook
- Visualization notebook
- Dashboard notebook
- Business insights notebook
- Reusable Python modules in `src/`

## Run it
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Open the notebooks in Jupyter.
3. Run the notebooks from top to bottom.

## Project structure
- `data/raw/`, `data/processed/`, `data/generated/`
- `notebooks/`
- `dashboards/`
- `reports/`
- `src/`
